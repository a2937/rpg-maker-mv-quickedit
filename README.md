# RPG Maker MV/MZ Quick Edit Tools README

## Features

This extension creates a custom text editor for RPG Maker MV data files like Actors, Maps, and so on.

Basically instead of being presented with just json, it registers an alternative view for editing the data. This view amounts to basically a local web page that interacts with the VS Code backend from what I understand.

The important part is it is graphical with fields and stuff. As for why this exists, I wanted to edit RPG Maker games far far away from my computer where
Steam wasn't installed. And with VSCode having a website version , I in theory wouldn't even have to download anything.

## Requirements

- None for end-users
- Developers will need NodeJS and pnpm though.
